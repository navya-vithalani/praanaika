# Praanaika assets

Placeholders are intentionally kept under these stable names so real brand files can replace them later without changing code.

## Brand

- `public/assets/brand/logomark.svg` - square symbol only; cream-safe version for headers, splash, and app icons.
- `public/assets/brand/logo-wordmark.svg` - horizontal Praanaika wordmark and symbol lockup.
- `public/assets/brand/logo-on-dark.svg` - light lockup for plum backgrounds.
- `public/assets/brand/favicon.svg` - square logomark favicon.

## App icons

- `public/icons/icon-192.svg` - current standard Android/PWA placeholder icon.
- `public/icons/icon-512.svg` - current large Android/PWA placeholder icon.
- `public/icons/maskable-512.svg` - current maskable PWA placeholder icon with safe padding.
- `public/apple-touch-icon.png` - final 180px iOS home-screen icon to supply later.

## PWA manifest

- `public/manifest.json` - install metadata, standalone display settings, theme colors, icons, and Today/Talk shortcuts.

## Product and story imagery

- `public/assets/avatars/avatar-01.svg` through `avatar-08.svg` - optional profile avatars.
- `public/assets/about/hub-photo.webp` - real Hub product photo.
- `public/assets/about/gem-photo.webp` - real Gem/Vayu product photo.
- `public/assets/about/view-screen.webp` - app screen or product-in-use image.
- `public/assets/about/praanaika-overview.pdf` - optional downloadable overview.

Until these are supplied, the shell uses the inline placeholder mark in `src/components/brand/BrandMark.tsx`.
